Documentation

Welcome to the ultimate guide for your AI Tool Finder application. This documentation covers everything from the initial setup for developers to a daily user guide for administrators.

Installation

  1. Unzip the File: Extract the project folder.
  2. Install Dependencies: Run npm install in your terminal.
  3. Setup Environment: Rename .env.example to .env.local and fill in your keys (MongoDB, Clerk, Stripe).
  4. Run Local Server: Execute npm run dev and go to localhost:3000.

Admin Panel Guide

The Admin Panel is the control center of your website. It allows you to manage content, users, and revenue.

How to Access?

1. Sign up/Login to the website as a normal user.

2. In your database (MongoDB), find your user document and change the role field content to admin.

3. Refresh the page, and you will see the Admin Dashboard link in the profile menu.

Managing Tools

This is where you manage the AI tools listed on your site.

Adding a Tool

Go to Admin > Tools and click "Add New Tool". Fill in the details like Name, Description, Website URL, and Pricing. You can upload a logo or provide a URL.

Reviewing Pending Tools

Tools found by the Auto-Scraper or submitted by users appear in the "Pending" tab.

  • Approve: Publishes the tool to the live site immediately.
  • Reject: Deletes the submission.
  • Edit: Modify details (like tags or description) before approving.

Category Management

Organize your tools into logical groups like "Chatbots", "Image Generators", etc.

  • Navigate to Admin > Categories.
  • Click New Category.
  • Enter a name (e.g., "Video Editing") and a slug (e.g., "video-editing").
  • Add a short description for SEO purposes.

News & Blog System

Drive traffic to your site by publishing articles.

Creating an Article

Go to Admin > News. The editor supports rich text, so you can add bold text, lists, and headers.

SEO Tips

Always add a "Slug" (URL friendly name) and a "Excerpt" (short summary) as these are used by Google for search results. Set the status to "Published" to make it visible.

Sponsorships & Ads

Manage your paid listings from Admin > Sponsorships.

  • Active Sponsorships: View which tools are currently paying for a "Featured" spot.
  • Advertising Plans: Create packages (e.g., "7 Days Featured for $50"). These plans appear to users when they try to promote their tool.

Site Settings

Configure global variables without touching code.

  • General: Site Name, Description, and Contact Email.
  • SEO: Global meta tags and keywords.
  • Social Links: Update your Twitter, Discord, or LinkedIn links in the footer.

User Guide

Submitting a Tool

Any logged-in user can submit a tool. This allows your directory to grow organically.

  1. Click the "Submit Tool" button in the top navigation.
  2. Fill out the multi-step form (Basic Info, Details, Media).
  3. Tip: Encourage users to add high-quality screenshots for better approval chances.
  4. Once submitted, the user can track the status (Pending/Approved) in their Profile Dashboard.

Bookmarks & Usage

  • Favorites: Users can click the icon on any tool card to save it for later. These are accessible in their Profile.
  • Voting: Users can upvote tools. Tools with more votes rank higher in "Popular" sorting.
  • Reviews: Users can leave 1-5 star ratings and written reviews on tool detail pages.

Auto-Scraper Engine

The system includes a smart script that scrapes TopAI.tools for new listings. You can automate this process so your site gets new content every day without you lifting a finger.

Manual Trigger (Testing)

You can run the scraper anytime by visiting this URL in your browser:

YOUR_DOMAIN/api/cron/scrape?key=YOUR_CRON_SECRET

Replace YOUR_CRON_SECRET with the value from your .env.local file.

Automating with Vercel Cron (Recommended)

If you deploy on Vercel, automation is built-in. We have included a vercel.json file in the project for you.

  1. Ensure your project has a file named vercel.json in the root folder.
  2. It should contain the following configuration:
{
  "crons": [
    {
      "path": "/api/cron/scrape?key=YOUR_CRON_SECRET",
      "schedule": "0 0 * * *"
    }
  ]
}
Important

You must update the path in vercel.json to match your actual CRON_SECRET before deploying!

Once deployed, Vercel will automatically trigger this route once every day at midnight.

Automating on VPS (Linux/Ubuntu)

If you host on your own server (DigitalOcean, AWS, etc.), use the system's crontab.

  1. Connect to your server via SSH.
  2. Open the cron editor: 
    crontab -e
  3. Add the following line to the bottom of the file: 
    0 0 * * * curl "https://your-domain.com/api/cron/scrape?key=YOUR_CRON_SECRET" >/dev/null 2>&1
  4. Save and exit (Ctrl+X, then Y, then Enter).

Explanation: 0 0 * * * means "Run at minute 0 of hour 0 (Midnight) every day".

Monetization Setup

To start earning money, you must configure Stripe.

  1. Create a Stripe Account.
  2. Get your Publishable Key and Secret Key from the Developer Dashboard.
  3. Add them to your .env.local file.
  4. Create a webhook endpoint in Stripe pointing to https://your-domain.com/api/webhooks/stripe and add the Signing Secret to your env file.
